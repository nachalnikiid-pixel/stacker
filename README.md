# 🏰 MAJESTIC Punishment Stacker

**by peep (discord: peepletmebleed)**

## Описание

Приложение для автоматического стакинга наказаний игроков с графическим интерфейсом.

## Возможности

- 🚫 Обработка команд `/ajail`, `/ban`, `/warn`, `/hardban`
- 📊 Автоматическая эскалация наказаний
- ⚙️ Гибкая настройка параметров стакинга
- 🎨 Несколько тем оформления (тёмная, классическая, majestic)
- 📋 Групповая обработка нарушений
- 💾 Сохранение и загрузка конфигурации

## Файлы

- `punishment_stacker.py` - основной модуль приложения
- `run_stacker.py` - простой запуск GUI
- `main.py` - главный файл для запуска в любой среде
- `test_commands.txt` - пример команд для тестирования
- `real_commands.txt` - реальные команды для обработки

## Запуск

### Для desktop окружения:
```bash
python main.py
```
или
```bash
python run_stacker.py
```

### В Replit:
Приложение покажет информацию и уведомление о необходимости desktop окружения для GUI.

## Настройки

Приложение поддерживает различные настройки:
- Лимиты времени для разных типов наказаний
- Коэффициенты эскалации
- Темы оформления
- Режимы группировки причин
- Обработка дубликатов

## Примеры команд

```
/ajail 123456 30 1.2.1 ПГО (01.01.2025) by Moderator1
/warn 123456 1.4 ПГО (01.01.2025) by Moderator2
/ban 123456 7 1.2.2 ПГО (02.01.2025) by Moderator1
```

После обработки будет создана оптимизированная команда с учётом всех наказаний.
