🏰 MAJESTIC PUNISHMENT STACKER
====================================
by peep (discord: peepletmebleed)

📋 ОПИСАНИЕ
-----------
Продвинутый стакер наказаний для объединения множественных наказаний одного игрока
в единую команду с автоматической конвертацией и эскалацией.

🚀 БЫСТРЫЙ ЗАПУСК
-----------------
1. Запустите: python run_stacker.py
2. Выберите файл с командами (или используйте real_commands.txt для тестов)
3. Укажите файл для сохранения результатов
4. Нажмите "⚡ СТАКНУТЬ"

⚙️ ВОЗМОЖНОСТИ
---------------
✅ Современный черно-красный дизайн с темами
✅ Настройка всех параметров стакинга через GUI
✅ Пользовательские формулы конвертации
✅ Предпросмотр результатов
✅ Сохранение/загрузка конфигураций
✅ Детальная статистика обработки
✅ Гибкая логика группировки причин

🎛️ НАСТРОЙКИ
------------
- Основное: выбор файлов, обработка
- Настройки: пороги наказаний, лимиты ПГО
- Логика стакинга: алгоритмы, формулы
- Предпросмотр: проверка результатов

🎨 ТЕМЫ
-------
- dark_red: Черно-красная (по умолчанию)
- majestic: Фиолетовая Majestic
- classic: Классическая светлая
